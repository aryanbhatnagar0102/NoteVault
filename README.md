# NoteVault

A simple Class 12 PCMB study website where you can find handwritten notes and video lectures chapter-wise in one place.

## Description

NoteVault is made for Class 12 students who want their study resources in one place instead of searching for notes and video lectures separately.The idea was to keep all the study resources in one place instead of searching for notes and lectures separately.
It includes resources for PCMB (Physics, Chemistry, Mathematics and Biology). Each subject has chapter-wise handwritten PDF notes and YouTube video lectures. 

## Features 

- Full class 12 PCMB - Physics, Chemistry, Mathematics and Biology resources at one place
- Chapter - wise handwritten PDF notes
- YouTube video lectures for all chapters
- Chapter accordion for easy navigation
- Video + PDF study workspace
- Dark and Light both mode available

## How it was built

NoteVault is a static website, so there is no backend or database.
The main structure and functionality were created using HTML and JavaScript. CSS is used for the handwritten notebook-style UI, dark/light mode and the different page layouts.

JavaScript handles the main functionality such as:
- Subject and chapter navigation
- Chapter accordions
- Opening PDF notes
- Embedding YouTube lectures
- Video + PDF study workspace
- Sidebar navigation
- Dark/light mode

The chapter information, PDF paths and video links are stored in JavaScript.
