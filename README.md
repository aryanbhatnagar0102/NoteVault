# NoteVault

NoteVault is a simple Class 12 PCMB study website where you can find handwritten notes and video lectures chapter-wise at one place.
The idea was to keep all the study resources in one place instead of searching for notes and lectures separately.

## Features

- Full class 12 PCMB - Physics, Chemistry, Mathematics and Biology resources at one place
- Chapter - wise handwritten PDF notes
- YouTube video lectures for all chapters
- Chapter accordion for easy navigation
- Video + PDF study workspace
- Dark and Light both mode available
